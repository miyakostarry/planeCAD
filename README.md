# X-Wing

A 3D model of an X-wing that I made in Autodesk Fusion.

## About this project

I started with a tutorial to get the basic shape: the body, the wings, the engines and the laser cannons at the wing tips. 

It was a X-wing tutorial on youtube

After that I kept going on my own and added more detail. I added panel lines on the wings, the red and yellow stripes, the blue cockpit window, the vent on top, and the text on the red stripe (MIYAKO on one side and HACK CLUB on the other).

## What I learned

- How to build something big in small pieces. I made a separate sketch for each part (body, nose, wings) instead of trying to draw everything at once.
- Learned about some cool tools draft, then few more i hardly ever used in my previous projects

## Files

| File            | What it is                                 |
| --------------- | ------------------------------------------ |
| `X-WING.step` | Works in most CAD programs                 |
| `X-WINGG.f3d` | The Fusion file, open it in Fusion to edit |
| `x-wing.stl`  | For 3D printing                            |
